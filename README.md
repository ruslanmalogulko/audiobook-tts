# audiobook-tts

Локальная озвучка русских EPUB: аудиокнига `.m4b` с главами, субтитры `.srt` и видео `.mp4`, где на экране текст фразы, которая сейчас звучит. Всё работает офлайн и бесплатно.

Книга на 6,5 часа озвучивается примерно за 10 минут на M4 Pro, видео собирается ещё за 5-10 минут.

## Быстрый старт

```bash
# 1. посмотреть главы, найти служебные (оглавление, список литературы, «об авторе»)
uv run book2audio.py "/путь/к/книге.epub" --list

# 2. пробник: 3000 символов одной главы, чтобы послушать голоса
uv run book2audio.py "/путь/к/книге.epub" --chapters 5 --limit 3000 \
  --speaker eugene --male-voice aidar --female-voice kseniya --name probe

# 3. вся книга без служебных глав, с видео
uv run book2audio.py "/путь/к/книге.epub" --chapters 3-58,60-63 \
  --speaker eugene --male-voice aidar --female-voice kseniya \
  --name "Название книги" --video
```

Результат появится в `output/`: `<name>.m4b`, `<name>.srt` и при `--video` ещё `<name>.mp4`.

## Флаги

| Флаг | Что делает |
|---|---|
| `--list` | показать главы с размером в символах и выйти |
| `--chapters 3-58,60` | какие главы озвучивать (номера из `--list`) |
| `--limit N` | только первые N символов каждой главы (пробник) |
| `--speaker` | голос рассказчика: `aidar`, `eugene` (муж.), `baya`, `kseniya`, `xenia` (жен.) |
| `--male-voice`, `--female-voice` | голоса реплик; без них вся книга читается одним голосом |
| `--video` | собрать `.mp4`: обложка слева, справа текущая фраза в цвете голоса |
| `--name` | имя итоговых файлов |
| `--no-accents` | не ставить ударения (быстрее, хуже) |
| `--engine f5` | экспериментальный движок F5-TTS (см. ниже), по умолчанию `silero` |

Повторный запуск продолжает с того же места: каждая фраза кэшируется в `output/<книга>/cache/`. Если поменять нормализацию или голос, перезвучатся только затронутые фразы.

## Как устроено

```
EPUB -> главы (по оглавлению) -> абзацы
     -> разбор голосов: рассказчик / мужская реплика / женская реплика
     -> фразы для субтитров (оригинальный текст)
     -> нормализация (числа, годы, века, сокращения, латиница) -> ударения RUAccent
     -> Silero v5 -> пауза -> кэш
     -> .m4b (главы + обложка + студийная обработка звука) + .srt + .mp4
```

**Решения, принятые на «Пути тимлида» (октябрь 2026), и почему:**

- **Silero v5, а не F5-TTS.** В слепом тесте Silero понравился не меньше, а F5 ошибается примерно в 5-7% слов против ~1% у Silero (проверка Whisper по каждой фразе) и работает в 30-60 раз медленнее. F5 остался в коде за флагом `--engine f5`; имеет смысл, только если записать 10-15 секунд живого голоса в `output/<книга>/refs/<голос>.wav` + `.txt`.
- **Студийная обработка `ffmpeg`, а не нейросетевой улучшатель.** В слепом тесте из четырёх вариантов (оригинал / студия / студия + комната / `resemble-enhance`) победила студия. Она занимает минуты, нейросеть заняла бы около 13 часов на книгу. Фильтр: `STUDIO_FILTER` в `book2audio.py`, громкость -18 LUFS, AAC 128k.
- **Голоса:** рассказчик eugene, мужские реплики aidar, женские kseniya.
- **Видео рисует Pillow, а не фильтр `ass` в ffmpeg:** Homebrew-сборка ffmpeg собрана без libass.

**Разбор голосов.** Реплика - абзац, начинающийся с тире. Ремарка («— сказал он. —») отделяется тире, перед которым стоит знак препинания, и только если в ней есть глагол прошедшего времени. Многоабзацные «письма» в кавычках тоже идут голосом реплик. Пол говорящего берётся (по порядку) из первого лица в реплике («я рада»), из ремарки («ответила Маргарита», через `pymorphy3`), из вводной строки с двоеточием, из чередования собеседников в диалоге; иначе мужской.

## Известные ограничения

- Когда в диалоге трое и у реплики нет ремарки, пол угадывается по чередованию и может ошибиться.
- Падежи чисел после предлогов не всегда верные («около один миллион»).
- Английские слова транслитерируются: частые из словаря, редкие по правилам («Thrones» -> «тронес»). Словарь `ENGLISH_WORDS` легко дополнять.
- Только русский. Для украинского у Silero есть модель `v4_ua`, но с одним мужским голосом (mykyta); понадобятся `ukrainian-word-stress`, `num2words(lang="uk")` и правки нормализации.
- `transformers` закреплён на `<5`: в 5.x ломается модель ударений RUAccent (`token_type_ids`).

## ⚠️ Тяжёлые модели и память

`resemble-enhance` на MPS с `PYTORCH_ENABLE_MPS_FALLBACK=1` на 2-минутном файле съел 56 GB и повесил Mac до принудительной перезагрузки. Любую незнакомую ML-модель запускай через сторож памяти, на коротких кусках и сначала на крошечном входе:

```bash
python3 memguard.py --max-gb 12 --min-free-gb 6 -- <команда>
```

Сторож убивает процесс со всеми потомками, если тот превысит лимит или если в системе останется мало памяти, и печатает пик.
